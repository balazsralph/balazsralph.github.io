Machine Learning Healthcare

Surgery Duration Prediction — PROBOCAL

delivered (script + tests) — hospital collaboration postponed

A scikit-learn pipeline predicting real surgery duration from data available at scheduling time — benchmarked against the hospital's own human estimates.

  • Designed a leakage-safe pipeline: intra-operative phase timestamps are excluded from the features, and a dedicated unit test locks that invariant.
  • Evaluated the model against the hospital's existing planned-duration baseline on the same test split, producing an explicit deployable / not-deployable verdict instead of a raw score.
  • Stress-tested on a synthetic dataset (2,500 interventions, 227 procedures, injected missing and corrupted rows), which surfaced a sparse-matrix incompatibility invisible on the 10-row demo sample — fixed before delivery.
  • Wrote 26 pytest unit tests validated by mutation testing: 6 deliberately injected regressions, each caught by the test designed to cover it.
Context
42AI × Centre Antoine Lacassagne (hospital, Nice). RNIPH / CNIL MR-004 compliance framework. Individual work, delivered — the hospital collaboration has since been postponed.

KFS-1 — a tiny x86 kernel

pair project — my part: the PS/2 keyboard driver

A bootable 32-bit x86 kernel in freestanding C and NASM assembly — GRUB/Multiboot boot, VGA text driver, PS/2 keyboard driver, libc-free kprintf.

  • My main contribution: the PS/2 keyboard driver — reading x86 I/O ports directly (inb), decoding make/break scancodes, handling Shift/Caps Lock and extended keys (arrows, Delete).
